# Crab AI

Crab AI 是一个多功能的人工智能应用程序，将多种 AI 功能集成到统一平台中，为 Windows、macOS、Android 和 iOS 设备提供流畅的使用体验。

## 功能特点

- **跨平台支持**
  - Windows 和 macOS 桌面应用
  - Android 和 iOS 移动应用
  - 所有平台保持一致的使用体验

- **统一的 AI 体验** 
  - 对话
  - 知识库
  - 工具
  - Agent
  - 更多功能...

- **灵活的部署方式**
  - 支持自托管服务器
  - 支持云端部署
  - 简单的设置和配置

## 架构设计

### 客户端
- 使用 Vue.js 构建的现代桌面和移动应用
- 原生平台集成
- 离线功能支持
- 实时同步

### 服务端
- 使用 Go 语言开发，确保高性能
- 支持 Docker 快速部署
- 可扩展的微服务架构

## 快速开始

### 服务端设置
1. 克隆代码仓库
2. 配置环境变量
3. 运行 `docker-compose up` 或从源代码构建
4. 服务器将在 `http://localhost:8080` 上运行

### 客户端设置
1. 下载适合您平台的客户端
2. 连接到您的自托管服务器或使用云服务
3. 开始体验统一的 AI 服务
