# Crab AI

> 🚧 Work in Progress - Actively Updating


[中文文档](README.zh-CN.md)

Crab AI is an all-in-one AI application that integrates multiple AI capabilities into a unified platform, providing a seamless experience across Windows, macOS, Android and iOS devices.

## Features

- **Cross-Platform Support**
  - Desktop apps for Windows and macOS
  - Mobile apps for Android and iOS
  - Consistent experience across all platforms

- **Unified AI Experience** 
  - Chat interface
  - Knowledge base
  - Tools
  - Agent
  - And more...

- **Flexible Deployment**
  - Self-hosted server option
  - Cloud deployment support
  - Easy setup and configuration

## Architecture

### Client
- Modern desktop and mobile applications built with Vue.js
- Native platform integration
- Offline capability
- Real-time synchronization

### Server
- Written in Go for high performance
- Easy deployment with Docker
- Scalable microservices architecture

## Getting Started

### Server Setup
1. Clone the repository
2. Configure environment variables
3. Run `docker-compose up` or build from source
4. Server will be available at `http://localhost:8080`

### Client Setup
1. Download the appropriate client for your platform
2. Connect to your self-hosted server or use cloud services
3. Start exploring the unified AI experience
